# Project Handoff: David Rudnick "STILL ALIVE" Poster Generator

## Project Overview

This project is a browser-based generative poster design system inspired by the visual language of David Rudnick's STILL ALIVE poster series.

The objective is not to create a direct recreation of any individual poster, but to reproduce the design logic that powers the series:

- Large-scale typographic anchors
- Structural connector systems
- Dynamic tension between image and type
- Controlled negative space
- Procedural composition
- Contemporary editorial aesthetics
- Physical print artifacts and surface simulation
